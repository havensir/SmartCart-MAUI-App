# 🛒 SmartCart

SmartCart is a .NET MAUI mobile application designed to help users track grocery spending and manage shopping budgets in real time.

---

## ‼️Development Workflow

To keep the project organized:

• Do not push directly to the `master` branch  
• Each team member works in their assigned branch  
• Pull requests should merge into `dev` first  
• After testing, `dev` will be merged into `master`

Branch assignments:

- ui-melissa
- backend-christopher
- logic-xander
- integration-isabella
---

## ✨ Features

- Create and manage grocery lists
- Add grocery items with estimated prices
- Automatically calculate a running total
- Set grocery budgets
- View remaining budget vs total spent
- Edit or delete grocery items
- Visual alerts when approaching or exceeding budget

---

## 🛠 Technology Stack

- .NET MAUI
- C#
- MVVM architecture
- SQLite (local storage)
- GitHub for version control
