# 🛒 SmartCart

SmartCart is a .NET MAUI mobile application designed to help users plan grocery spending before they shop. Instead of purchasing groceries, the app focuses on estimating costs, managing grocery lists, and comparing store pricing to help users stay within budget.

## ▶️ How to Build and Run

1. Open the project in **Visual Studio 2022**  
2. Restore dependencies (if prompted)  
3. Select a target device:  
   - Windows Machine  
   - Android Emulator  
4. Click **Run (▶️)** to build and launch the application

---

## 🎯 Project Goals

The main goal of SmartCart is to help users better understand and control their grocery spending by:

- Combining grocery list management and budgeting into one app  
- Providing estimated item pricing to calculate totals before shopping  
- Allowing users to compare store pricing for better value  
- Helping users avoid overspending through budget awareness and alerts  


## ✨ Features

- Create and manage a grocery list  
- Add items with estimated prices by category  
- Automatically calculate a running total  
- Set, update, or clear grocery budgets  
- View estimated total vs. budget  
- Search for items by keyword or department  
- Compare pricing across stores using publicly available data  
- Automatically default totals to the lowest-priced store  
- Edit or delete grocery items  
- Receive alerts when approaching or exceeding budget

## 📌 Project Overview

SmartCart was developed as part of a Mobile Device Programming course at the University of Cincinnati. The application focuses on improving how users plan grocery spending by combining budgeting, list management, and price comparison into one mobile experience.

## 🚧 Project Scope & Future Potential

SmartCart has the potential to be expanded with more advanced features, such as real-time pricing integrations, personalized recommendations, and full store-level item comparisons.  

However, due to project scope and academic constraints, the current implementation focuses on estimating average pricing for common items within major grocery departments across selected local Cincinnati grocery stores.
